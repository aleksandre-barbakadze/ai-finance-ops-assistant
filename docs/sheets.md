# Spreadsheet structure

All logic reads sheets **by header name**, so column order mostly does not matter (exceptions are noted).
Columns marked *(plain text)* must be formatted as **Format → Number → Plain text** before pasting data, otherwise Sheets turns IDs, months and ranges like `1-30` into numbers or dates.

## Master data
- **Suppliers**: Supplier ID, Name, Country, Currency, Payment terms, VAT payer (GE), Default category, IBAN *(plain text)*, Recurring
- **Customers**: Customer ID, Name, Type, Payment terms (days), Credit limit (GEL), IBAN *(plain text)*, Contact email, Notes
- **FX rates**: Date, USD, EUR, Source (filled by `loadFxRates`)

## Synthetic sources ("truth", used only by generators and for scoring)
- **Invoice source**: one row per document (Invoice ID, Template, File name, supplier fields, IBAN, Items `name|qty|price; …`, Net, VAT, Total, Hidden note, …)
- **Answer key**: Invoice ID, True supplier ID, True invoice number, True invoice date, True due date, True currency, True net, True VAT, True total, Expected flag, …, Expected payment status
- **Receipts source**: Receipt ID, Date, Customer ID, Payer IBAN *(plain text)*, Amount (GEL), Bank reference, Applies to (truth)
- **AR answer key**: Invoice No, Expected status, Days late / overdue, Expected outstanding (GEL), Expected aging bucket *(plain text)*, Expected control flags
- **Card sales (shop)**: Month *(plain text)*, Card sales (GEL), Source, Expected status, Expected difference (GEL)
- **Payment run key**: Invoice ID *(plain text)*, Expected in run, Expected amount, Expected reason

## Working sheets
- **Invoices** (filled by Extractor/Validator/Reconciler): Invoice ID, File name, File link, Supplier ID, Supplier name, Invoice number, Invoice date, Due date, Currency, Net amount, VAT amount, Total amount, AI confidence, AI flags, Status, Processed at, Supplier IBAN, Supplier tax ID, Document type, AI notes, Model, FX rate, Total GEL, Category, Check flags, Payment status, Paid amount, Payment note, **Payment decision** (dropdown APPROVED / HOLD / BLOCKED), Decision note, Decided by
- **Bank** (filled by bank generator) – *column positions are used*: A Txn ID *(plain text)*, B Date, C Account, D Description, E Counterparty, F Counterparty IBAN *(plain text)*, G Debit, H Credit, I Currency, J Match status, K Matched invoice, L Match note, M AR match
- **Sales invoices**: Invoice No, Customer ID, Issue date, Due date, Net (GEL), VAT (GEL), Total (GEL), Description; columns I–P are written by `reconcileReceivables`
- **Forecast sales**: Month *(plain text)*, Card sales (GEL), COD sales (GEL), Basis
- **Forecast costs**: Item, Amount, Currency, Day, From *(plain text)*, To *(plain text)*, One-off date *(plain text)*, Scenario (BASE / PESSIMISTIC), Basis

## Generated by code
Test results, AR reminders, Payment run, Cash forecast, Forecast detail, Dashboard.
